# KK Crystal Elements – billing app

Node/Express invoice generator (`npm start`, port 4321) with Tally-style PDF
invoices, WhatsApp shorthand quick-billing, E-way Bill JSON and Tally XML export.

For any accounts, GST, TDS, trademark, Tally, registration, billing (from PI /
PO / WhatsApp text) or WhatsApp/e-mail reply work, delegate to the
`accountant` subagent (`.claude/agents/accountant.md`). It asks clarifying
questions before creating bills or committing to amounts.
